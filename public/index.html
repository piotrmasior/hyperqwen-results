Earlier thinking tests: why a small output budget failed

At a 2,048-token allowance, all four xhigh tasks exhausted the budget in reasoning without a final answer. Larger allowances helped some tasks; 147k input left too little output headroom. Length-capped timings measure time to failure, not time to a completed answer.

Hardware & software

Model revisions and serving profiles

What the metrics mean

Prefill
Server first-scheduled to first-generated-token time. Includes first-token generation; not a GPU-kernel-only trace.
Decode rate
(Generated tokens − 1) / server generation seconds. Reasoning tokens are included.
Total latency
Client request-to-response time, including LAN and streaming overhead. Startup and prompt preparation are excluded.
Cold input
Zero cached input tokens, with the model and kernels already loaded. Not a cold process start.
Output tokens
API completion usage, including reasoning. Retokenized reasoning and answer text may differ because of parser delimiters.
